## Spec

依据老师的四项功能清单、插件 README 和统计图实施方案，发现并修复两项 P2 问题：

1. **分类/分页响应乱序。** 快速从“已通过”切到“尝试过”，如果前一个请求最后返回，旧列表会覆盖新结果。列表加入请求序号，成功和失败均忽略过期响应，选中分类使用返回结果的状态。
2. **主页被列表请求阻塞。** 原先等待列表完成才加载统计、成长曲线和训练场次；换绑时还可能暂留旧图。现在列表与统计独立加载，主页刷新也有序号保护；按 bindingId 清理旧内容，两个服务返回前重新确认绑定。

班级删除、本人手动题目/比赛标记删除未发现其他可复现功能或权限缺陷。AC 去重、Gym、题库字段回退、标签分母符合实施口径。

本轴共 2 项问题，均已修复并回归通过；无已确认未修复功能问题。
