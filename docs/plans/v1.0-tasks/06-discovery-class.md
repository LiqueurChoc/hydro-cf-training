# T06 · 修复切班筛选与请求乱序

先读[执行约定](README.md)。依赖：无，建议按整体编号执行。对应 F4。

## 目标

选赛结果、翻页和创建草稿使用同一当前班级；旧班级的结果不能在切班后继续显示为有效结果。

## 实施范围

主要修改 `templates/cf_training_app.html` 中 discovery、参赛班级选择、搜索、分页和刷新处理，扩展模板浏览器回归。

切班即清除旧结果和分页状态，保留合理搜索条件并重新查询或明确要求搜索。每次查询捕获班级、条件和请求序号；成功/失败响应均验证是否仍为当前请求，旧错误也不能覆盖新成功状态。刷新后班级被删除、授权撤销或名单改变时，不沿用失效的筛选结果。

## 验收

- A 班搜索后切 B，旧结果立即失效；B 的翻页及创建请求均为 B。
- A 慢 B 快、A 快 B 慢、连续搜索和分页乱序，最终只显示最新选择对应结果。
- 旧请求失败不覆盖当前成功结果；空班级、无可管理班级、权限撤销都有明确状态。
- 桌面和手机模板回归通过，不影响学生统计和班级榜已有请求隔离。
