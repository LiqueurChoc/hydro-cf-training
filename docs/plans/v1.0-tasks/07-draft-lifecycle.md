# T07 · 补齐草稿取消与改期

先读[执行约定](README.md)及 T01—T05 交接。依赖：T01—T05。对应 F5。

## 目标

未及时发布的草稿可以安全退出或改期，不会永久锁住成员换绑。

## 实施范围

新增教练“取消草稿”和“修改草稿开赛时间”操作，沿用训练管理权限；受托班级管理员不会因此获得全域训练操作权。

取消保留原记录与操作者审计，取消状态不能发布、签到、修改资格或结算，也不再阻止换绑。取消与发布并发时以原子状态条件决定一个合法结果，重复取消不重复副作用。

草稿改期必须为未来时间，包括已经过期的草稿；保留题目和成员配置，发布时重新筛查，已有预览/同步依据按适用范围失效。已发布或已结算训练不能走草稿接口。

梳理全部状态读取路径：列表、详情、换绑、自动同步、创建数量限制及导出。不要仅加按钮。取消不删除档案，也不表示容量已释放；保留现有存储安全上限并说明取消记录仍占存储，真正归档留给后续功能。

## 验收

- 昨日草稿取消后可换绑；另有有效草稿/未结算训练时仍锁定。
- 过期草稿改到未来后可重新筛查并发布，已发布比赛不能改期。
- 取消/发布/换绑并发保持合法状态，学生与受托管理员操作被拒绝。
- 取消记录可追溯，既有训练、评分和班级关系保持正确。
